# Flower Delivery App (Client)

This is the **client-side application** for a flower delivery service. The project is built with **React** and **TypeScript** following modern best practices such as state management with **Redux Toolkit**, form handling with **React Hook Form**.

---

## Features

- 📦 Product catalog browsing with server pagination
- 🛒 Shopping cart functionality
- 🗺️ Set address via Google Maps and show locations of shops with products in the cart
- 🧾 Order creation

---

## 🛠 Tech Stack

- TypeScript
- React
- React Router
- Redux Toolkit
- Axios
- React Loading Skeleton
